# نظام تفريغ البصمات تلقائياً إلى جدول الدوام

يقرأ هذا البرنامج ملف `attlog.txt` الصادر عن جهاز البصمة، ويحوّله تلقائياً إلى جدول دوام
بصيغة Excel — مع معالجة كل الحالات الخاصة التي تظهر في بيانات الجهاز.

> **الإصدار 2.4 — النسخة النهائية**: نافذة سطح مكتب أصلية بواجهة ويب عربية RTL
> (ثيم داكن/فاتح، خط Cairo مضمّن، مؤشرات KPI، جداول تفاعلية، تقارير داخل التطبيق).
> نقطة الدخول الجديدة: `desktop_app.py` — وواجهة Tkinter القديمة ما زالت متاحة عبر `app.py --gui`.

## ⬇️ تنزيل النسخة النهائية (EXE جاهز — بدون تثبيت Python)

## 1) التشغيل السريع — بدون تثبيت Python

1. شغّل `build.bat` مرة واحدة على جهاز فيه Python مثبّت → ينتج ملف `AttendanceDump.exe`
   في مجلد `dist` (يحتاج اتصال إنترنت أول مرة لتنزيل PyInstaller).
2. بعد ذلك يعمل الملف `.exe` على أي جهاز Windows بدون Python إطلاقاً.
3. انسخ `settings.json` بجانب ملف الـ exe — فيه الربط والملاحظات.

## 2) التشغيل السريع — مع Python

```
pip install -r requirements.txt
python desktop_app.py        # الواجهة الحديثة v2 (موصى بها)
python app.py --gui          # واجهة Tkinter الكلاسيكية (v1)
```

أو مباشرة من سطر الأوامر:

```
python app.py --attlog "attlog.txt" --year 2026 --month 9 --out "دوام سبتمبر.xlsx" ^
              --csv "تحقق.csv" --quality "تقرير_الجودة.txt"
```

## 3) خطوات الاستخدام الشهرية (دقيقتان)

1. افتح البرنامج → تبويب **التوليد** → اختر ملف `attlog.txt` → حدد الشهر والسنة → **قراءة ومعاينة**.
2. إن ظهرت أرقام غير مربوطة: اذهب لتبويب **الربط**، اكتب الاسم العربي كما في القالب لكل رقم، واحفظ.
   *يتم هذا مرة واحدة فقط لكل موظف جديد.*
3. أدخل الاجازات والمأموريات في تبويب **الملاحظات** (تاريخ + رقم وظيفي + نص).
   تبقى محفوظة ولا تُفقد عند إعادة التوليد.
4. ارجع لتبويب **التوليد** → **توليد Excel** → احفظ الملف.
5. افتح **تقرير الجودة** وراجع النواقص قبل اعتماد الجدول.

## 4) القواعد المعتمدة في المعالجة

| القاعدة | التفصيل |
|---|---|
| عمود الحالة يُتجاهل | الأدلة أثبتت أنه غير موثوق؛ نعتمد الترتيب الزمني فقط |
| اقتران اليوم | أول بصمة = دخول، آخر بصمة = خروج |
| بصمة واحدة قبل 12:00 | دخول + ملاحظة «نقص بصمة خروج» |
| بصمة واحدة بعد 12:00 | خروج + ملاحظة «نقص بصمة دخول» |
| أكثر من بصمتين | الوسطى تُسجل في الملاحظات «خروج وعودة: 12:34» |
| التكرار | بصمتان لنفس الموظف بفارق أقل من دقيقتين = بصمة واحدة (قابل للتعديل من الإعدادات) |
| تنسيق الوقت | `h:mm` مثل `8:05` بدون ثوانٍ |
| الملاحظات المحفوظة | «اجازة/مأمورية» تُدمج مع ملاحظات النظام، وتظهر حتى بلا أي بصمة |
| أيام العطلة | بصمات الجمعة/السبت تظهر كتحذير في تقرير الجودة ولا تُدرج |

جميعها قابلة للضبط من `settings.json` أو تبويب الإعدادات (خط منتصف اليوم، حد التكرار،
قاعدة التأخير بعد 8:15 — التفعيل لاحقاً عند طلبك).

## 5) وضع القالب (مطابقة 100%)

- ضع مسار ملف قالبك الأصلي في تبويب **الإعدادات** (أو مرّره بـ `--template`).
- البرنامج يفتح **نسخة** من قالبك ويعبّئ القيم في أماكنها — كل التنسيق (ألوان، دمج،
  حدود، RTL) يبقى كما هو حرفياً.
- يتطلب أن تكون خلايا التواريخ في القالب **قيم تاريخ حقيقية** وليست نصاً.
- إن لم يتوفر قالب يعمل المولّد الاحتياطي: نفس البنية الموصوفة (شريط الأحد+الاثنين
  وشريط الثلاثاء–الخميس، 3 أعمدة لكل يوم، صفوف فاصلة لأصحاب المناصب، ورقة RTL).

## 6) ملف الإعدادات settings.json

```json
{
  "dedup_seconds": 120,          // حد دمج البصمات المكررة
  "midday_split": "12:00",       // الفاصل لتحديد نقص الدخول/الخروج
  "late_after": "08:15",         // قاعدة التأخير (معطلة حالياً)
  "late_enabled": false,
  "workdays": [6, 0, 1, 2, 3],   // الأحد=6، الاثنين=0 ... الخميس=3
  "template_path": "",           // مسار قالبك الأصلي (اختياري)
  "employees": [ {"id": 1025, "template_name": "يزن أبو بايع", "no_punch": false} ],
  "notes": { "2026-09-20|1017": "اجازة" }
}
```

- الربط **دائماً عبر الرقم الوظيفي** وليس الاسم.
- الموظفون أصحاب المناصب الذين لا يبصمون: ضع `"no_punch": true` ويُترك `id` فارغاً
  (يظهرون كصفوف فاصلة بالجدول).

## 7) تقرير الجودة — ماذا يعني كل بند؟

- **أرقام غير مربوطة**: موظف يبصم لكن لم يُربط باسم في القالب → اربطه من شاشة الربط.
- **أيام بنقص بصمة**: تحتاج مراجعة (البصمة الناقصة غالباً لا يسجلها الموظف).
- **خروج وعودة**: الموظف خرج وعاد أثناء الدوام — تأكد أنها مقبولة.
- **بصمات أيام عطلة**: غالباً موظف تختبر الجهاز أو دخل يوم عطلة.
- **موظفون بلا أي بصمة**: صفهم سيبقى فارغاً — تحقق (إجازة بدون تسجيل؟).
- **أسطر تالفة/مكرر محذوف**: للعلم فقط، استُبعدت تلقائياً.

## 8) اختبار القبول (أهم خطوة قبل الاعتماد)

ولّد ملف سبتمبر 2026 من `attlog` الحقيقي وقارنه **خلية بخلية** مع ملفك اليدوي الحالي.
أي اختلاف يُسجل كخطأ ويُصلح قبل الانتظام على البرنامج. استخدم ملف `--csv` المرفق
مع كل عملية توليد للتحقق السريع (عمود بعمود) قبل فتح Excel.

## 9) مشاكل شائعة

| المشكلة | الحل |
|---|---|
| الأسماء تظهر رموزاً غريبة | الملف بترميز ANSI — البرنامج يكتشفه تلقائياً (utf-8 / utf-16 / cp1256)؛ إن فشل أرسل لنا أول 3 أسطر |
| لم أجد خلايا تواريخ في القالب | خلايا التاريخ نصية وليست تاريخاً — حوّلها في Excel إلى تاريخ حقيقي أو استخدم المولّد الاحتياطي |
| موظف يبصم ولا يظهر | رقمه غير مربوط — شاشة الربط |
| الملاحظة المحفوظة لا تظهر | الصيغة `YYYY-MM-DD|رقم_الموظف` مثال `2026-09-20|1017` |
